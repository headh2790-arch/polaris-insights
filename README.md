# Polaris Insights

Build the frontend for a production-quality capstone called:
POLARIS — AI Policy Intelligence Studio
Use the attached POLARIS project document as the functional source of truth and the attached dashboard image as visual inspiration.
POLARIS is an India-focused AI policy-impact decision-support platform.
IMPORTANT:
This is NOT a generic chatbot and NOT a universal policy prediction system.
Quantitative prediction is currently focused on:
EV / Transportation policies, especially EV purchase subsidies.
The quantitative model is:
TWFE / Difference-in-Differences + Event Study.
POLARIS can analyse other policies using RAG + LLM, but must NOT fabricate numerical state-level predictions when a validated quantitative model does not exist.

- Subtle green/red indicators
- Rounded cards
